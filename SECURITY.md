# Security policy

## Supported versions

Avenward is pre-release software. No version is currently supported for public
internet or production deployment.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Until a dedicated
security mailbox exists, contact the repository owner privately through their
verified GitHub profile and include only the minimum reproduction information.
Do not include real credentials, customer data, or workplace logs.

## Safe testing

Test only systems and data you own or are explicitly authorized to use. Do not
perform destructive testing, denial of service, credential attacks, or public
scanning in connection with this project.

See the [threat model](docs/security/threat-model.md) for current boundaries.

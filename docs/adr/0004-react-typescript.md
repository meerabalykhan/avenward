# ADR 0004: Use React and TypeScript for the frontend

- Status: Accepted
- Date: 2026-07-23

## Decision

Use React, strict TypeScript, and Vite. Add routing, server-state management, and
an accessible component library when application workflows require them.

## Consequences

The ecosystem supports typed, testable browser workflows. Dependency growth must
remain deliberate; the foundation does not add a large UI framework prematurely.

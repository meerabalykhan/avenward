# ADR 0010: License the repository under Apache License 2.0

- Status: Accepted
- Date: 2026-07-23

## Decision

Use Apache License 2.0 for the initial open-source code and maintain NOTICE,
third-party license, and trademark documents.

## Consequences

The license permits broad use and includes an explicit patent grant. It does not
grant trademark permission. Dependencies and contributions must remain license
compatible, and a legal review is required before a public commercial release.

# Avenward roadmap

The detailed, gate-based roadmap is maintained in
[`docs/development/development-roadmap.md`](docs/development/development-roadmap.md).

- `0.0.1` — foundation
- `0.1.0` — authenticated event explorer and synthetic data
- `0.2.0` — real ingestion foundation, safe detection rules, and alerts
- `0.3.0` — incident management, vulnerability findings, and audit history
- `0.4.0` — asset, endpoint-visibility, and NOC monitoring
- `0.5.0` — explainable anomaly and exposure analysis
- `0.6.0` — grounded AI explanations
- `0.7.0` — reports, notifications, and approval-gated response actions
- `0.8.0` — production identity, security integrations, and hardening
- `0.9.0` — MSP-ready release candidate, deployment, and recovery
- `1.0.0` — first public release after all release gates pass

Version `1.0.0` targets a defensive operations platform, not a collection of
unsafe or immature substitutes for specialist products. Endpoint protection,
firewall enforcement, vulnerability scanners, and penetration-testing tools are
integrated and orchestrated where appropriate. Native enforcement is limited to
reversible, explicitly approved actions. Avenward does not claim autonomous
offensive capability, analyst replacement, or a staffed 24/7 monitoring service.
